# 2026-01-31 작업 기록

## PWA 적용

### 배경
- 꿈결 앱을 모바일에서 네이티브 앱처럼 사용할 수 있도록 PWA 전환 논의
- 앱스토어 출시 방법도 검토 (PWA, Capacitor, React Native 비교)
- 우선 PWA까지만 적용하기로 결정

### 작업 내용

1. **next-pwa 설정** (`next.config.mjs`)
   - `next-pwa` 패키지 연동
   - 개발 환경에서는 비활성화 (`disable: process.env.NODE_ENV === "development"`)

2. **manifest.json 생성** (`public/manifest.json`)
   - 앱 이름: "꿈결 - 무의식의 예술"
   - display: standalone (주소창 없는 모드)
   - 테마 컬러: #7c3aed (보라), 배경: #0f172a (다크네이비)

3. **layout.js 메타데이터 추가** (`src/app/layout.js`)
   - manifest 링크, appleWebApp 설정 추가
   - `themeColor`와 `viewport`를 별도 `viewport` export로 분리 (Next.js 16 규격)

4. **PWA 아이콘 생성** (`public/icons/`)
   - 기존 `KkumGyeolLogo.jsx` SVG를 기반으로 192x192, 512x512 PNG 생성
   - 다크 배경 + 보라색 그라데이션 로고 + "꿈결" 텍스트

5. **.gitignore 업데이트**
   - `sw.js`, `workbox-*.js` 등 next-pwa 자동 생성 파일 제외

### 빌드 이슈 및 해결
- **문제**: Next.js 16은 기본 Turbopack 사용, next-pwa는 webpack 전용 → 빌드 에러
- **해결**: `package.json`의 build 스크립트에 `--webpack` 플래그 추가
